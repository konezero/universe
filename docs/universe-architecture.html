Main Server universe_server.py

Monolithic Python HTTP server (~33k lines). Contains the SQLite-backed data store (UniverseStore), the threaded HTTP server (UniverseHTTPServer), and the request handler with all 80+ API routes. The central hub that every other component connects to.

Provider Abstraction

Three AI providers are supported through parallel implementations at every layer.

Terminal Layer
resolve_cli_executable() resolves claude/grok/codex. startup_argv() builds provider-specific flags. ConPTY spawns any of the three.
Session Gateway
GrokAcpSession, CodexAppServerSession, ClaudeCodeSession — JSON-RPC stdio bridges per provider.
Master Runtime
GrokProjectMasterRuntime, CodexProjectMasterRuntime, ClaudeProjectMasterRuntime — per-provider master implementations.
