# Universe Project MASTER Inbox

Status: project-owned dispatch inbox
Owner: Universe Project MASTER

This directory is the registered delivery boundary for approved Universe
dispatch envelopes addressed to this project's `MASTER` Mode.

Room conversation, provider session transcripts, Task Frame journals, and
general Memory Sync records do not belong here. Universe may append only an
explicitly approved dispatch envelope through the registered `master_inbox`
reference. The receiving Project MASTER decides whether and how to act on it.

Inbox delivery does not create authority, an Execution Assignment, source
write permission, or Task Frame execution permission.
