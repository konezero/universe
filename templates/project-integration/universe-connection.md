# Universe Connection Contract

Owner: Universe project-integration template catalog

## Boundary

The Project publishes only approved, bounded, redacted candidates to its
connected Universe. It does not install a Career Carrier, grant Project source
execution authority, or expose raw prompts, source, command logs, or Worker
transcripts.

```text
Project Task Frame or Project Master
  -> approved redacted queue candidate
  -> durable queue receipt
  -> Universe ingest
  -> Bench, composition, or later Career promotion candidate
```

Universe owns asynchronous ingest. Career consumes only explicit
Universe-to-Career promotion candidates. Rendezvous is not in this path.
